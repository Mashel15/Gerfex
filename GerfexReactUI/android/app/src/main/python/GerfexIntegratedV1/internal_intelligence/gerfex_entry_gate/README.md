# Gerfex Intelligence Gateway V2

## الهدف

هذا المجلد هو الباب الرسمي الوحيد بين Gerfex وتطبيقات/نماذج الذكاء.

## القاعدة العليا

لا يجوز لأي جزء من Gerfex أن يتواصل مع أي نموذج ذكاء داخلي أو خارجي من خارج هذا الباب.

هذا الباب مسؤول عن الاتجاهين:

1. دخول نماذج الذكاء إلى Gerfex.
2. خروج Gerfex إلى نماذج الذكاء.

## المسارات المعتمدة

### 1) learning_to_gerfex
مسار قادم من صفحة التعلم إلى Gerfex.
يستخدم للنقاش والاقتراح والاعتماد والرفض.

### 2) main_gma_to_gerfex
مسار قادم من GMA العادي إلى Gerfex.
يستخدم عندما يحتاج المسار الرئيسي إلى عقل داخلي.

### 3) gerfex_to_internal_model
مسار خروج Gerfex إلى نموذج ذكاء داخلي.

### 4) gerfex_to_external_model
مسار خروج Gerfex إلى نموذج ذكاء خارجي مثل ChatGPT أو DeepSeek لاحقًا.

## المنع

ممنوع التواصل المباشر بين Gerfex وأي نموذج ذكاء من خارج هذا الباب.

أي مسار خارج هذه البوابة يعتبر legacy أو غير معتمد حتى يتم عزله أو تحويله.

## الهدف المعماري

Gerfex يبقى الأصل والمدير.
نماذج الذكاء تدخل وتخرج عبر بوابة واحدة فقط.
هذا يسمح باستبدال GMA أو إضافة نماذج خارجية لاحقًا دون كسر Gerfex.
